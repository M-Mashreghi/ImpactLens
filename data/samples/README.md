# Sample data (synthetic / public demo only)

Everything in this folder is fabricated or public reference data for demos and tests.
**Never place a real private portfolio here.** Private files belong outside the repo
(e.g. `data/private/`, which is git-ignored).

| Path | Contents |
|---|---|
| `securities.json` | Demo security master (public tickers + fictional ambiguity fixtures) |
| `relationships.json` | Provenance-backed supplier/customer/competitor links (demo citations) |
| `factor_exposures.json` | Demo country/commodity/macro sensitivities |
| `portfolio_demo.csv` | Synthetic portfolio (market values) |
| `news/*.json` | Synthetic news articles (one is a deliberate syndicated duplicate) |
| `analyses/*.json` | Curated fixture LLM outputs keyed by title (used by `LLM_PROVIDER=fixture`) |
| `prices/*.csv` | Synthetic daily closes, generated by `scripts/generate_sample_prices.py` |
| `eval/labeled_v1.jsonl` | Labelled offline evaluation set |
